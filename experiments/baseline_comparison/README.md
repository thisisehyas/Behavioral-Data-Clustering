# Baseline Clustering Comparison

## Objective

Compare K-Means, DEC Frozen, DEC Trainable, and IDEC using the same observations and seven standardized composite features.

## Models

- K-Means (k=5)
- DEC Frozen (k=5)
- DEC Trainable (k=5)
- Final IDEC (k=5)

Existing DEC and IDEC cluster labels will be reused, these models will not be retrained.

## Evaluation Protocol

All four models were evaluated in the original seven-dimensional standardized feature space using the following internal clustering metrics:

- **Silhouette:** higher is better.
- **Davies–Bouldin:** lower is better.
- **Calinski–Harabasz:** higher is better.

All three metrics were calculated on the full dataset of 99,997 observations for every model.

### Feature-Space and Label Validation

Before evaluation, the following checks were performed:

- Confirmed that the common feature matrix has shape `(99997, 7)`.
- Verified that DEC Frozen and IDEC load `dataset/X_scaled.csv`.
- Verified that DEC Trainable loads `embeddings/X_scaled.npy`; this matrix has the same shape and exactly matches `dataset/X_scaled.csv` in values and row order.
- Confirmed that each model has 99,997 labels and five nonempty clusters.
- Confirmed that the inference procedures preserve input row order, based on the inspected code.

These checks establish feature-matrix compatibility and label-array alignment, assuming the saved labels were generated by the inspected code paths.

## Results

The evaluation produced the following comparison:

| Model | Silhouette ↑ | Davies–Bouldin ↓ | Calinski–Harabasz ↑ |
|---|---:|---:|---:|
| K-Means | 0.1226 | 1.6786 | 16,509.5876 |
| DEC Frozen | 0.0896 | 2.0025 | 13,604.6264 |
| DEC Trainable | 0.0754 | 2.1870 | 11,645.2335 |
| IDEC | 0.0794 | 2.0763 | 13,256.0439 |

K-Means achieved the most favorable values across all three metrics in the original feature space. These results do not establish that K-Means produces more psychologically meaningful or useful roommate-compatibility profiles; that requires separate evaluation.

## Important Distinction

Previously reported DEC/IDEC metrics calculated in the learned latent space are retained separately. They are not directly compared numerically with metrics calculated in the original seven-dimensional feature space, because the evaluation spaces differ.

## Reproducibility

Experiment settings, input paths, random seeds, and evaluation choices are recorded in `config.yaml`.

K-Means was fitted using `random_state=42` and `n_init=20`. The existing DEC and IDEC labels were reused without retraining.
